# Everyday reliability upgrade

Existing features remain available. No new top-level navigation page is added.

| Requested feature | Result and entry point | Verification |
| --- | --- | --- |
| Fix playback | Player context menu / More and failure prompts explain observed connection, decoding, sound and subtitle conditions. Choose another source, reload or restore sound explicitly. Copyable diagnostics omit titles, URLs and credentials. | Browser exercises actual controls; advice unit tests; existing source rollback journeys. |
| Reliable source memory | After 10 seconds of sustained decoding and position advancement, remember the working add-on, quality and audio language on this device. A small scoring bonus respects filtering and explicit source ordering. Existing per-title audio memory remains authoritative. Forget preferences in subtitle accessibility settings. | Clock-driven browser test, profile/private-session tests and existing ranking tests. |
| Private session | Existing Incognito toggle also guards direct resume/history/source-memory writes. Unified refresh and scheduled Argus account pushes/pulls pause; earlier queued edits are retained. Existing provider scrobble guards remain in place. | Persistence and sync tests. Requests already sent before enabling Incognito cannot be recalled. Manual exports/sharing are explicit actions. |
| Household handoff | Player help sends the current source, current clock position and semantic track choices over the existing LAN remote WebSocket. Receiver must accept. Success requires a matching decoded position and selected tracks; failure leaves original playback available. | Protocol/failure/track-position tests. Both ends require this desktop implementation and receiving Phone remote enabled. Localhost/file-only sources and credential-header-only sources cannot be transferred. Native Android projector compatibility is not claimed. |
| Offline travel | Downloads checks actual completed files, matching external subtitle sidecars and available space at the chosen folder. Missing files and permission failures remain distinct. | File existence/error tests. Embedded subtitle languages remain explicitly unverified until playback; language-suffixed sidecars are not automatically counted. |
| Explain availability | Existing picker distinguishes unavailable add-ons, missing debrid, expired credentials, uncached sources, webpages, insecure URLs and unsupported formats. Playback help complements it with runtime diagnosis. | Existing picker and resolve tests; no duplicate availability service. |
| Device readiness | Settings → Advanced → Repair tests real decoding of a bundled silent VP8 fixture, receives navigation input and reports network connectivity. Downloads supplies disk/file checks; existing connection health probes configured services. | Browser decodes fixture and receives key input. This is not 4K/HDR or native-decoder certification. |
| Update recovery | Existing Updates → Backup & Restore retains recovery backups, earlier builds, explicit install confirmation and the coordinated signed desktop release gate. | Existing updater, backup, manifest and publishing regression tests. |
| Accessibility presets | Subtitle settings offers readable subtitles, speech clarity and larger UI/reduced motion presets with Undo. Uses existing settings scope and preserves other preferences. | Bounded preset tests, typecheck and production build. OS reduced-motion settings remain respected. |
| Personal release calendar | Existing watchlist/calendar and episode reminders retained. Movie reminders now check dated provider releases and notify once per release date, without claiming that a stream is available. | Date-window and duplicate tests plus existing calendar/reminder tests. Reminders run while Argus is open; no background OS scheduling claim. |

Release evidence includes scoped lint/typecheck, full regression tests, production frontend builds and 20 real Chromium bridge journeys. Installer builds and physical-device journeys are separate evidence; these checks do not certify every account, source or OS/device combination.
