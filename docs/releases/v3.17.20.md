- **macOS Main-Thread Responsiveness Fix (`v3.17.20`)**:
  - **Offloaded Blocking IPC Commands**: Converted `settings_read`, `settings_write`, `secrets_read`, `secrets_write` (`src-tauri/src/settings_store.rs`), and `temp_usage_bytes` / `temp_clear` (`src-tauri/src/temp_prune.rs`) from synchronous main-thread IPC handlers (`WebURLSchemeHandlerCocoa::platformStartTask`) to `async fn` handlers backed by `tokio::task::spawn_blocking`, preventing disk I/O and recursive temp directory scans from freezing the macOS AppKit main thread.
  - **Cross-Platform Build Parity**: Includes all Windows x64/ARM64, Android (`jni` 0.21), and iOS (`tauri ios build --archive-only`) release pipeline fixes from `v3.17.19`.
